Are you a https://UseGalaxy.org user? Have you ever been doing an analysis and thought "If I could just run a python script here" and then downloaded the data, ran the script, and then uploaded it back to Galaxy to continue on? Have I got the thing for you: 


Galaxy has implemented User Defined Tools, where you can specify a python script (and use anything from @bioconductor@genomic.social) that can run in Galaxy. We're rolling this out to a select set of users. Want in? 


Sign up: https://udt-signup.galaxyproject.org

More info: https://galaxyproject.org/tools/user-defined-tools/
